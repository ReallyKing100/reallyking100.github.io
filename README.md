# 🚀 DevTeam

✨ A simple landing page for a multidisciplinary digital team. It showcases web development, mobile and desktop apps, AI automation, data analysis, the team, and a contact form that starts a WhatsApp conversation.

## 📁 Project structure

```text
.
├── index.html   # Page content and sections
├── styles.css   # Layout, styling, and responsive design
├── script.js    # Menu, animations, counters, and contact form
└── README.md    # Project overview
```

## 🖥️ Run locally

Open `index.html` in a browser. No build tools or dependencies are required. 🚀
